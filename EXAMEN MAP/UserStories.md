# User Story 1
Als Bezoeker van de site wil ik een overzicht van de tassen kunnen zien, zodat ik weet wat voor soort tassen er zijn.
Priority: Hoog
Tijdsindicatie: Extra lang

Acceptatie Criteria:

    Pagina met alle tassen
    Kleine teksten per tas

# User Story 2
Als bezoeker van de site wil ik op een foto in het portfolio klikken, zodat ik meer details kan zien over de tas.
Priority: Hoog
Tijdsindicatie: Extra Lang

Acceptatie Criteria:

    Foto is Clickable
    leid door naar Detail page
    Detail page bevat meer info over tas, zoals naam, kleuren etc.

# User Story 3
Als bezoeker wil ik contact kunnen openemen met de bedrijfseigenaar, zodat ik vragen kan stellen.
Priority: Hoog
Tijdsindicatie: Kort

Acceptatie Criteria:

    Er is een Contact pagina
    Deze bevat alle gegevens van de bedrijfseigenaar
    Eventueel formulier voor directe vragen.

# User Story 4
Als bedrijfs eigenaar wil ik een product kunnen toevoegen, zodat ik zelf nieuwe producten kan toevoegen zonder daar iemand anders voor te hoeven in te schakelen.
Priority: Laag
Tijdsindicatie: Lang

Acceptatie Criteria:

    Pagina met overzicht alle producten
    Toevoeg knop
    Klikken op de knop opent een formulier
    Producten kunnen een naam, afbeelding, kleuropties (moet ook 1 kunnen accepteren) en beschrijving krijgen
    Producten worden zonder errors toegevoegd
    Producten wordn gelijk na toevoegen getoond in portfolio

# User Story 5
Als bezoeker wil ik contact kunnen opnemen met de bedrijfseigenaar, zodat ik kan een email en andere gegevens kan vinden voor het vragen naar een eventuele samenwerking / collab.
Priority: Hoog
Tijdsindicatie: Kort

Acceptatie Criteria:

    Er is een Contact pagina
    Deze bevat alle gegevens van de bedrijfseigenaar
    Eventueel formulier voor directe vragen.

# User Story 6
Als bedrijfs eigenaar wil ik een product kunnen bewerken, zodat ik zelf producten kan wijzigen zonder daar voor iemand anders voor te hoeven in te schakelen.
Priority: Laag
Tijdsindicatie: Lang

Acceptatie criteria:

    Overzichtpagina met alle producten
    Wijzig knop
    Klikken geeft formulier
    Alle velden hebben hun waardes al ingevuld
    Na submitten van formulier worden de producten zonder errors gewijzigd
    wijzigen zijn meteen zichtbaar in portfolio

# User Story 7
Als bedrijfseigenaar wil ik producten kunnen verwijderen, zodat ik niet meer beschikbare producten niet toon.
Priority: Laag
Tijdsindicatie: Extra Kort

Acceptatie Criteria:

    Overzichtpagina met alle producten bevat verijderknop naast de producten
    Verwijderknop verwijder het product uit de database
    Product wordt zonder errors verwijderd
    Product is ook meteen niet meer zichtbaar in portfolio

# User Story 8
Als gebruiker wil ik op de front/homepage naar de contact pagina kunnen gaan via de navbar, zodat ik contact op kan nemen als dat nodig is.
Priority: Hoog
Tijdsindicatie: Extra Kort

Acceptatie Criteria:

    Er is een navbar aanwezig.
    Deze bevat linkjes naar de contact pagina en portfolio

# User Story 9
Als bezoeker wil ik via een link/logo naar de instagram van de bedrijfseigenaar, zodat ik kan zien wat ze nog meer heeft gedaan/gemaakt.
Priority: Middel
Tijdsindicatie: Extra Kort

Acceptatie Criteria:

    In de footer link/logo naar de instagram van de bedrijfseigenaar.
    Zelfde link/foto moet ook terugkomen op de contact pagina.
    Ook de detail en homepage krijgen deze functie.

# User Story 10
Als gebruiker wil ik graag op de homepage/frontpage naar het portfolio gaan van alle tassen zodat ik alle tassen kan zien.
Priority: Hoog
Tijdsindicatie: Extra Kort

Acceptatie Criteria:

    Er is een link aanwezig in de navbar.
    Ook afbeeldingen op de homepage worden een link naar het specifieke product in de portfolio.
    Daarnaast komt er een CTA-knop naar het portfolio.

# User Story 11
Als bezoeker wil ik de 3D omgeving zien op de product detail page, zodat ik gelijk tassen kan bekijken in 3D en aanpassen.
Priority: Middel
Tijdsindicatie: Extra Lang (schatting, geen idee hoelang de gamers echt nodig hebben)

Acceptatie Criteria:

    Op de Product Detail page wordt de 3D omgeving getoont.
    Deze is volledig bruikbaar (wordt gemaakt door de Gamers)
